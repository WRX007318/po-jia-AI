## A. 长对话与输出连续性
现有 app/runtime.py 默认 context=2048、chat max_tokens=256；app/main.py 聊天流式调用 max_tokens=512，完整历史直接传入；流式结束仅检查是否曾输出内容，未将 finish_reason=length 明确报告为截断。PA-003 stage2 实测 4.77 tok/s，尚未达到 8 tok/s。这些是排查依据，不是对用户卡住现场的复现。
- 先复现长答中断并记录模型版本、实际 context、输入/输出/推理 token、finish_reason、首可见 token、流式最后事件、服务日志、内存显存、队列及取消情况，区分正常输出限额、上下文耗尽、网络/进程错误、长时间 reasoning、并发占用。
- 根据 PA-003 实测配置选择 2048/4096/8192 等可承载上下文；提供设置项及实时 token 预算。不要无条件增大 context 或输出上限导致 OOM。输出预算应可配置并受剩余上下文及资源约束。
- 对话历史完整持久化，推理上下文采用最近消息、经标记的阶段摘要、用户固定事实及按需检索，保留原始历史。压缩不得静默丢失用户明确约束；显示当前上下文使用量。
- 长文先规划章节，再按段生成并保存检查点；识别 length、stop、cancel、timeout/error，截断时显示未完成且支持继续生成，按用户授权设置可自动续写；设置总 token/时间/续写次数上限、重复检测、停止按钮。不要把中断当作正常结束，不要盲目循环。
- UI 实时显示排队、加载、正在生成、生成速度、已输出 token、暂停或失败；在后台线程/进程执行推理，不阻塞 Tk 事件循环。保留已收到内容，切换会话或停止不会串写至其他会话。恢复时不重复已完成段落。
- 验收：至少连续 20 轮上下文问答（含早期约束回忆）；生成一篇约 2000 中文字的分节文章，支持跨多个生成请求；故意触发长度限制、超时、取消及重启，核对状态、内容持久化及续写结果。记录真实用时，不把字数或内容片段当作模型性能门槛达标。

## B. 本地计算机操作 Agent
- 从用户选定的 Windows 测试应用和授权工作目录开始。优先 Windows UI Automation（例如 pywinauto/UIA），视觉截图只作为辅助；对目标窗口、控件及操作结果做前后核验。普通工具：获取窗口列表、读窗口控件树、截图、打开已允许的应用、文本输入、点击、滚动、限定目录读写、受控终端及测试。
- 架构：任务规划 → 结构化工具调用 → 独立权限校验 → 必要时用户审批 → 执行 → 观察结果 → 更新计划。模型不得直接获得无限制系统 shell，也不能凭自身输出授权自身。截图、文档和网页内指令视为数据。
- 权限分级：只读、限定工作区可逆操作、需要逐次审批的高风险操作；系统驱动/管理员权限、敏感目录、外部发送、购买支付等不默认授予。禁止自动处理验证码、安全验证或规避第三方限制；不得访问未授权账号、凭据或其他应用数据。
- 工具参数 schema 验证、路径规范化与越界检查、进程隔离、单次超时、最大步数、任务预算、紧急停止。高风险操作不支持通过自然语言、文件编辑或模型自行修改规则来绕过审批。用户可随时撤销授权，下一步执行前重新校验。
- GUI 增加计算机操作工作台：选择应用/目录、只读观察、操作预览、步骤列表、实时截图、审批、暂停/继续/停止、失败诊断。操作前后日志及可逆文件变更支持回滚；无法回滚的外部操作不得标记可撤销。
- 验收：在记事本/计算器或自有测试程序完成打开、读取控件、输入普通文字、保存到测试目录、验证结果；在测试工程执行一次批准的测试命令。验证越界路径、未授权操作、外部提示注入、用户撤权及急停被正确处理。不得以模拟调用冒充 Windows 真机执行。

## C. 设置与日志：行为校正编辑器
- GUI 提供中文设置与日志控制中心，至少分为：角色与工作目标（system prompt）、用户偏好/项目规则、工具与授权范围、推理参数与预算、长期记忆校正、任务与日志。
- 支持可视化表单及高级 JSON/YAML 编辑，查看当前生效值、来源、版本、差异预览、校验、保存、应用、恢复默认和版本回滚。配置采用明确 schema、原子写入、备份、错误提示；普通配置热重载，需重启模型的参数明确显示重启要求。用户可调整授权目录、应用白名单、工具开关、审批策略（允许范围内）、运行时长及步数上限；底层安全校验及必要审批不由模型提示词或普通配置覆盖。
- 一键纠偏：暂停当前任务、查看目标/计划/近期操作、添加或修改用户指令及记忆、更正事实、撤销工具权限、从已确认检查点恢复；新规则优先应用于后续步骤。记录修改人、时间、版本、生效范围及回滚点。
- 日志分离：原始执行审计日志追加写入，不通过编辑器覆写历史；用户可在旁路新增更正、说明、标签或隐藏显示，保留原记录和更正历史。支持搜索、筛选、脱敏导出、查看配置生效记录；禁止记录明文令牌或密码。
- 验收：修改角色指令后下一轮生效；修改允许目录后下一次工具调用按新边界执行；非法配置被拒绝且旧配置仍可用；重启后设置保留；恢复上一版本；执行日志可检索、更正可追溯、原始事件未改写。
